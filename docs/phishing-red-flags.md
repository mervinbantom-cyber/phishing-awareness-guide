# Signs of a Phishing Message

## Common red flags
- Urgent or threatening language ("Your account will be closed!")
- Sender address that looks slightly wrong (for example support@paypal.com)
- Requests for passwords, PINs or personal details
- Unexpected attachments or links
- Spelling mistakes and a generic greeting like "Dear user"
- Offers that seem too good to be truee
  
## What to do
1. Do not click links or open attachments.
2. Check the sender's real address.
3. Hover over links to see where they lead.
4. Report it to your IT or security team.
5. Delete the message.
